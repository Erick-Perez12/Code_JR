# CODE JR

Prototipo de interfaz HCI construido con Vite, React, TypeScript y Tailwind CSS.

## Requisitos

- Node.js 18 o superior
- npm

## Desarrollo

```bash
npm install
npm run dev
```

## Compilar

```bash
npm run build
```

El resultado de producción se genera en `dist/`. Para previsualizarlo localmente, ejecuta `npm run preview`.
